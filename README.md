# 🚢 Kubernetes — From Docker to Work-Ready

A hands-on, coached course that takes you from *"I know Docker"* to
*"I can deploy, debug, and operate apps on Kubernetes."*

## How to use this course

Each module is one markdown file. Work them **in order**. For every module:

1. Read the file (concept → diagram → cheatsheet).
2. Do the **🧪 Practice** section on your own cluster — run the commands.
3. Clear the **✅ Check yourself** challenge.
4. We mark it done below and `git commit`.

> **Live practice:** the file is the lab sheet; in chat you run the commands,
> paste the output, and I coach + debug with you. Just say *"next"* or
> *"let's do Module N"* when you're ready for a module.
